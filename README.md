# SAT Grammar Lab

Interactive SAT grammar practice with 27 original questions, eight rule topics, a 10-question challenge, mistake review, and browser-saved progress.

## Run locally

Open dist/index.html in a browser. No installation or build step is required.

Progress is saved in the browser's local storage.
